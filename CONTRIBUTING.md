# Contributing

Bug reports and compatibility results from other **Dell OptiPlex 7090 Micro** owners are welcome.

Before proposing support for another Dell model, please understand that Dell SMM/WMI behavior can differ between systems. Do not assume a fan state or firmware override has identical semantics on another model.

## Useful issue information

- Dell model
- CPU
- BIOS version
- Windows version
- Dell Command | Configure version
- observed Level 1 / Level 2 / MAX RPM
- Dell Sensor 0 behavior under load
- relevant `Dell7090FanControl.log` lines

Please remove private identifiers before posting logs.
