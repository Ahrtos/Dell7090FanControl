# Dell7090FanControl v1.0

First public release of Dell7090FanControl for the **Dell OptiPlex 7090 Micro**.

## Highlights

- Manual Level 1 (~1140 RPM)
- Manual Level 2 (~3980–4000 RPM)
- MAX (~5560–5800 RPM)
- Dell BIOS Auto restore
- Adjustable two-stage automatic fan curve
- Default 55 °C / 45 °C thresholds
- Live temperature and RPM monitoring
- Color-coded system-tray icon
- Windows autostart
- Persistent-MAX safety verification
- Responsive progress feedback during mode changes

## Requirements

- Windows 11
- Administrator privileges
- Dell Command | Configure for MAX mode

## Important

This release was developed and tested on a **Dell OptiPlex 7090 Micro**. Other Dell models are not automatically supported.

`FanCtrlOvrd` used by MAX mode is persistent on the development machine. Read the README and hardware notice before experimenting with MAX.
